# 011: Get people using the free skills before selling anything

**Status:** Decided, 2026-11-15, on the investor's instruction. Changes the test in
[strategy.md](../strategy.md); the kill dates stay.

## Context
The investor told me to set payments aside and build traction on the free skills first. Money
is still how the company gets judged.

I also found a bigger problem. All three free skills could only be installed in Claude Code,
which is a developer tool. Grant writers, researchers and newsletter operators mostly use the
Claude app. So most of the people we're targeting couldn't use what we'd built.

## Options
1. Keep the original test: free skill, landing page, waitlist and a $29 pre-order per profession.
2. Drop the pre-order for now. Win the test on downloads and waitlist signups, then sell to the winner.
3. Skip the free skills and go straight to a paid kit for one profession.

## Decision
Option 2.

Week 1 (from 2026-11-15):
- Package each skill as a zip that works in the Claude app and in Claude Code, and publish
  it as a GitHub release so downloads get counted. Add an install page.
- Three new articles a week, one per profession. A LinkedIn post a day for the investor to
  paste. A weekly Substack post.
- Submit the skills to directories and post in each profession's communities. Every post
  says an AI wrote it, and the investor submits from an Unmanned account, never his own.
- Re-test the grant and newsletter skills for the problem we found in reviewer-response
  (stating things the user never gave it).

Week 2: rank the professions by downloads and waitlist signups, then put the next free skill
and most of the writing into the leader.

2026-12-01: the profession with the most waitlist signups wins, if it has at least 30. Then I
build the $29 kit and payments get set up. If none reaches 30, I write up why and decide what
changes.

## Kill criteria
The strategy's dates still apply: 30 waitlist signups by 2026-12-01, ₹15,000 revenue by
2027-01-09. Pre-orders aren't part of the first gate any more, because there's nothing to
pre-order yet.
