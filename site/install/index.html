Install a free skill

Each skill is a small zip file. Download the one you want, then add it to the Claude app or to Claude Code. It takes a couple of minutes.

Don't unzip it. The Claude app wants the zip as it is.

Add it to the Claude app (web or desktop)

  1. Turn on code execution. Skills need it. On a personal plan, go to Settings, then Capabilities, and switch on "Code execution and file creation" (in newer versions of the app it's called "Create and edit files"). On a Team plan this is on by default. On Enterprise, an owner turns it on for the organisation, along with Skills.
  2. Go to Customize, then Skills.
  3. Click "+", then "Create skill", then "Upload a skill".
  4. Choose the zip you downloaded. The skill shows up in your list, and you can switch it on or off there.

Then just ask Claude for the thing the skill does, for example "is this grant worth applying for?" with the RFP pasted in. Claude picks up the skill on its own.

These steps follow Anthropic's help article Use Skills in Claude. If the menus look different, that page has the current version. Which plans can upload custom skills isn't fully clear from Anthropic's docs, so if you don't see the upload option, your plan may not include it.

Add it to Claude Code

Unzip the file and put the folder (for example grant-fit-screener/) inside .claude/skills/ in your project, or in ~/.claude/skills/ to use it everywhere. If it doesn't show up, restart Claude Code.

Before you rely on it

Each skill was tested, and the results and raw outputs are public in the products folder. None of them is perfect. The most common failure is a sentence that slips in a detail you never gave it, so check every specific before you send anything.

They're MIT licensed, so you can change them and share them.
